How To Play

Each level shows a maze of cells separated by walls. Some cells contain numbered checkpoints (1, 2, 3, ...) — the last checkpoint is marked with a 🏁 flag.

  • Tap a cell adjacent to "1" to start the path.
  • Continue tapping cells sharing an edge with the last cell, with no wall between.
  • The path must visit checkpoints 1 → 2 → 3 → ... → flag in order.
  • Cells cannot be revisited, and you cannot cross walls.
  • Press Enter to check, U to undo, R to restart.
  • You have 3 hints per level (press H).

Each puzzle has exactly one unique solution. Find it!
