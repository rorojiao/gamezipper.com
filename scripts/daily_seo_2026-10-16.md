### v5.13 (本次 cron) — mihomo DNS Poisoning 修复 (by cron 直接绕过)

**问题**:
- v5.12 (2026-10-02) 修了 mihomo HTTPS_PROXY=7890 dead proxy

- 任何 `curl --noproxy '*'` 仍 TCP → fake-IP → mihomo 尝试连接 dead upstream → TLS 卡 15s
- **唯一解**: 跳过 DNS, 用 `--resolve host:443:CF_REAL_IP` 直连 Cloudflare

**绕过方案 (本次 cron 应用)**:
```bash
CF_IPS="104.21.0.0 104.21.54.15 172.67.155.15"  # CF Anycast range
for ip in $CF_IPS; do
  curl --noproxy '*' --http1.1 --max-time 15 \
    --resolve gamezipper.com:443:$ip \
    -o /dev/null -w "code=%{http_code}\n" \
    https://gamezipper.com/robots.txt
done
```

**已知 CF IP (验证可达)**:
- gamezipper.com → 104.21.62.168 / 104.21.54.15 / 172.67.155.15 (任选)
