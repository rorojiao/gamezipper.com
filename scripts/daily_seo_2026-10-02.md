## 🆕 本轮修复 (2026-10-02)

### 🪲 v5.12 mihomo-dead proxy env purge (P0)
**症状**: 脚本 `daily-seo-health.py` v5.11 在 mihomo 完全下线后,所有 fetch 返回 HTTP 0(`subprocess.run` 即使带 `--noproxy '*'` 仍受 HTTPS_PROXY env 影响,curl 第一连接仍撞死端口)。

**根因**: `mihomo` clash 进程未运行,port 7890 (HTTP_PROXY) + 9090 (API) 都 refuse connection;shell session 仍 export `HTTPS_PROXY=http://127.0.0.1:7890`,curl 在 `--noproxy '*'` 解析前 race condition 仍尝试 dead proxy 触发 SSL_ERROR_SYSCALL / 15s timeout。

**修复** (`daily-seo-health.py:121-180`):
```python
import os as _os
env = {k: v for k, v in _os.environ.items()
       if k.lower() not in ("http_proxy", "https_proxy", "all_proxy", "no_proxy")}
# 2-attempt retry with 1s backoff (covers CF Pages h2→h1.1 one-shot transients)
for attempt in (1, 2):
    result = subprocess.run(args, env=env, ...)
    if 200 <= status <= 299: return ...
    if attempt == 1: _t.sleep(1.0)
return 0, f"curl failed after 2 attempts: {last_err}"
```

**效果**: 9/9 endpoint 立即恢复 ✅ (gz.com + tools 全部 curl --http1.1 + Mozilla UA + env purge)。
