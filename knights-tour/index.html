Move a chess knight across the board in L-shaped leaps (2+1 squares). Visit every square exactly once — numbered 1 to N² in visit order.

How to Play

  1. Tap a square to place the knight on the highlighted start square (orange).
  2. Tap any L-shaped square (2 squares + 1 perpendicular, in any of 8 directions) to move there.
  3. The number on each square shows your visit order — start is 1, then 2, 3, …
  4. Each square can only be visited once. Plan ahead — every move is permanent.
  5. You win when every square is numbered.
  6. Hint lights up the best Warnsdorff square (fewest onward moves). Undo takes back the last move.
  7. Bigger boards = bigger puzzles. The 10×10 Expert tier has 100 moves to plan.
