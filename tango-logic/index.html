How To Play Tango Logic

You get a 6×6 grid with some cells pre-filled as clues (highlighted). Between some adjacent cells you'll see either = (the two cells must be the same) or × (the two cells must be different).

Your task: tap empty cells to place ☀️ suns or 🌙 moons so all of these are true at once:

  • Each row has exactly 3 suns and 3 moons.
  • Each column has exactly 3 suns and 3 moons.
  • No three identical symbols appear consecutively in any row or column.
  • Every = marker connects two equal symbols.
  • Every × marker connects two different symbols.

Controls:

  • Tap a cell to cycle Sun → Moon → empty.
  • H — fill an empty cell with the correct answer (3 hints per level).
  • Enter — check whether your grid is correct (auto-fires when full).
  • R — restart the level.
  • Esc — back to level select.
  • M — toggle music.

Scoring: 3 stars for finishing with no hints. 2 stars with 1 hint. 1 star with 2-3 hints. Each puzzle has exactly one verified unique solution — find it!
