How to Play Set Quest

The rule: a SET is three cards where, for EVERY attribute, the three cards are either all the same or all three different.

Example: one red circle · two red circles · three red circles — a SET (same color, all-different numbers).

Attributes: shape (circle/square/triangle), color (red/green/purple), number (1/2/3) and — from Easy tier on — shading (solid/striped/outline).

Goal: every board contains exactly one SET. Select its three cards to win. 0 errors + 0 hints = 3 stars.

Controls: tap a card to select, tap again to deselect. A wrong triple costs an error. Hint flashes one solution card (3 per level, costs a star). Undo reverts the last pick. Check evaluates your current selection. Keyboard: H hint · C check · U undo · R reset · Ctrl+Z undo · ←/→ level · Esc back.
