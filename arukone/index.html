🧩 Arukone Number Link
Connect numbered pairs with continuous paths. Fill every cell.

How to play:

• Each number appears twice on the grid

• Draw a path connecting each pair of identical numbers

• Paths are made of orthogonally adjacent cells (up/down/left/right)

• Every cell must be covered by exactly one path

• Paths can touch each other diagonally, but cannot share cells

Controls: Tap a number to start its path, drag through cells to extend. Tap the same number again to finish.
