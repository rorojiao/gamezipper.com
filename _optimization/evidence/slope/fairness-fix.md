# slope 公平性修复记录(2026-08-16)

## Before(三重缺陷,300 次插桩证实)
1. **碰撞模运算回卷**:dz=((roadZ−obs.z)%ZLOOP+ZLOOP)%ZLOOP,新生障碍(−1180 mod 1200=20)落进碰撞窗 dz<30 → 出生即撞("闪撞"),B2 代理 300 次插桩 100% 死于此,最佳存活 8.4s,30s 存活数学不可达
2. **剔除过早**:filter 保留 dz<1020,而障碍真正到达需 residual 绕回 0 → 实际还有 180 距离就被删,真实威胁从未发生
3. **预置障碍同点叠 8 个**:resetWorld 连调 8 次 spawnObstacle(),全部生成在同一 z(roadZ+1180),随机车道铺满路面 = 6.25s 后准时到达的必死之墙(39/40 死亡 bestGap 0.19–0.36 < 0.44 通过需求)
4. **渲染位置冻结**:project() 吃 obs.z 绝对取模而非相机相对距离,障碍屏幕位置不动

## After(修复后)
- 碰撞/收集/剔除/渲染/排序统一为带符号相对距离 obs.z − roadZ
- 碰撞窗 = 前方 30z + 物理重叠尾 15z(标准"通过即安全"手感)
- 预置障碍沿环路均匀展开(160+i·120);生成时相邻 z<150 的车道间隔强制 ≥0.55(防双人墙)
- 预置宝石同步展开
