### sudoku verifier detail (3 real gate defects)
1. **Uniqueness never proven.** The only signal was "avg min candidates" — a puzzle can have a single-candidate cell and still admit many full solutions. Replaced with a real **independent** solver (re-implemented, MRV-ordered, `limit=2`), cross-checked against the engine's own `countSolutions`, plus a check that the stored solution is byte-identical to the solution the solver materialises. Result: 30/30 unique, 0 disagreements, worst case 22 ms.
2. **cwd-shadow read (Pitfall #55 class — same bug R963 fixed in 10 QA scripts).** `path.join(SLUG,'index.html')` resolved against `process.cwd()`, so `cd sudoku && node verify_engine.js` died with ENOENT while the repo-root invocation worked by luck. Anchored to `__dirname`; both cwds now produce identical output.
3. **Unreachable levels not detected** — the loop only covered the indices present in `TIERS`; a shrunken catalog would silently print PASS.

**Negative test (gate proven to fire):** injecting an empty board (many solutions) → `NOT UNIQUE (independent solver found 2)` + **exit 1**; the real catalog → **exit 0**. Restored and re-verified after the negative test.
