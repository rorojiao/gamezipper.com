"""Pentomino Fill level generator.

Rules: given an outline shape and a subset of pentomino pieces, place pieces
inside the outline so they fully cover it without overlap. Each piece can be
rotated (and reflected for asymmetric pieces).

Strategy:
  1. Hand-craft outline shapes per tier with known-unique solution.
  2. Verify each level has exactly 1 valid placement via backtracking solver.
  3. If a hand-crafted shape fails, regenerate with a different shape.

Difficulty tiers (6 levels each, 30 total):
  - Beginner: 5-10 cells (1-2 pieces), simple shapes
  - Easy:     15-20 cells (3-4 pieces), 1 cut
  - Medium:   20-25 cells (4-5 pieces), 2 cuts
  - Hard:     25-30 cells (5-6 pieces), complex shapes
  - Expert:   30-35 cells (6-7 pieces), irregular shapes
"""

def normalize(piece):
    min_r = min(r for r, c in piece)
    min_c = min(c for r, c in piece)
    return tuple(sorted((r - min_r, c - min_c) for r, c in piece))


def rotate_cw(piece):
    return tuple(sorted((-c, r) for r, c in piece))


def reflect(piece):
    return tuple(sorted((r, -c) for r, c in piece))
