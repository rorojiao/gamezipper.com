## MEMORY (sweep 127)

- **petal-path level tiles use `<div class="level-btn">` not `<button>`**: sweep 126 lesson was "level tiles are buttons"; this sweep found an exception. First-click probe must use both `button` and `.level-btn` selectors. Confirmed in `petal-path/index.html` line 308-310: `btn.className = 'level-btn';` then `grid.appendChild(btn)`. The element is a `<div>` with click handler attached via `btn.onclick`. Detection: `document.querySelectorAll('.level-btn').length > 0` is a strong indicator of div-tile pattern.
- **stained-glass informational multi-solution design (Pitfall #51)**: graph-coloring puzzles can have multiple valid colorings when clue density is low. Verifier's independent coloring counter found 8/30 levels (all 4×4 with 9-10 clues + nc=3, plus 5×5 with 11-12 clues) with >=2 clue-consistent colorings. Engine checkWin is EXACT match with stored solution, so alternate valid colorings cannot win. This is acceptable because: (1) catalog/UI makes no claim of uniqueness, (2) the canonical solution always wins, (3) the player can always reach the canonical solution via the same color-cycling input that the verifier uses. Per Pitfall #51, only flag if (a) catalog claims uniqueness but data has multi (P1 doc drift) OR (b) generator claims uniqueness but data has multi (P0 generator bug). Neither condition holds for stained-glass → informational only.
- **numbrix 2-step click flow**: `▶  Start Game` (button text starts with emoji + spaces) → level tiles (`.lvl` class buttons with numeric content) → game screen. The "Start Game" button has `\u2003` whitespace ("▶  Start Game" with double em-space) — R336 emoji-prefix regex `[\u2000-\uFFFF\w]*` correctly matches it. The level grid has 35 total cells (Beginner 4 + Easy 4 + Medium 6 + Hard 8 + Expert 13 = 35 — actually it's `tier-row` containers with `.lvl` buttons each).
- **electromagnet-field auto-runs on load** (no menu gate): canvas renders immediately at 392×392 with full game state. The "Check" / "Reset" / "Undo" buttons are always visible from start.
