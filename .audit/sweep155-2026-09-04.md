### Pitfall #50 cwd-shadow bug in `doppelblock/verify_python.py` (local-only)
- **Symptom**: `python3 doppelblock/verify_python.py` from cwd=repo-root throws `KeyError: 'N'` (succeeded from cwd=doppelblock).
- **Root cause**: `open('levels.json')` is cwd-dependent, fails when run from repo root during sweep-batch invocation.
- **Fix**: Replaced with `open(os.path.join(os.path.dirname(os.path.abspath(__file__)), 'levels.json'))` + `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))` for `gen_levels` import.
- **Verified**: `python3 doppelblock/verify_python.py` from repo root → 30/30 PASS.
- **Note**: file is gitignored (`*.py` not in exception list) so the fix is local-only; the pattern is documented in sweep47 Pitfall #50 for future-script-author reference.
