## Lessons (R313)

- **Nikoli-menu-gated probe pattern** (sweep-48) applies to tango-logic too: 3-screen `screen-title → screen-levels → screen-game` cascade; clicking `.level-btn` with text=1 is the entry. Documented in the probe recipe.
- **Multi-canvas disambiguation by ID + size** (R1) continues to hold: cookie-clicker uses `#cookie-canvas` 340×340 main + `#gc-canvas` 70×70 mini; tangram uses `#c` 860×497 main + `#tc` 160×160 preview. Largest-canvas rule + ID pick both work.
- **BI rage_click signal can be misleading** — the top 4 offenders (cookie-clicker, flappy-wings, tangram, antistress) all have shipped fixes AND still PASS their verifiers. The high event counts likely reflect legacy / sparse test users (UV=31/36/21/19 for 1506/388/331/292 events = 49/11/16/15 events-per-UV) — not a regression. Pattern: stale rage_click counts ≠ active bugs.
- **TouchEvent ctor** in headless eval requires `Touch` constructor or fails. Use plain `MouseEvent('click')` for click-loop probes when game supports both. Touch-handlers are usually registered but may not be needed for desktop verification.
- **CDP "Inspected target navigated or closed"** = popunder hijack pattern (R336). When first Play button click triggers popunder → fresh session + skip Play click → use direct function call / state probe. Re-opened 2 sessions cleanly recovered.
